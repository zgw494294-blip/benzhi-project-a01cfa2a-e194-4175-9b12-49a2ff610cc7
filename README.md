# 射线底片判读放行台

本项目面向工业无损检测团队，将射线检测建档、不可变底片修订、自动完整性检查、人工缺陷判读、返拍复验、证据冻结和质量放行凭据纳入一条可追溯流程。浏览器工作台和同源 JSON API 均由 Go 服务提供，业务数据保存在本地 SQLite，底片载荷按 SHA-256 摘要寻址保存。

## 构建

```sh
go build ./cmd/server
```

项目使用系统 SQLite 动态库 `libsqlite3.so.0`，构建环境需要启用 CGO。项目内适配器实现 `database/sql` 所需接口，无需下载第三方 Go 模块。

## 运行

```sh
go run ./cmd/server -addr=127.0.0.1:19081 -data-dir=./data
```

默认监听 `127.0.0.1:19081`。也可通过 `PORT` 指定端口，服务仍绑定 `127.0.0.1`。为保护检测资料，`-addr` 只接受回环地址。打开 `http://127.0.0.1:19081/` 即可使用工作台。

服务角色通过页面右上角切换，对应 API 请求头 `X-Role`：`operator` 提交任务和底片，`reviewer` 执行检查、判读、返拍和冻结，`quality` 签发放行凭据。所有写请求都要求 `expectedVersion` 和 `idempotencyKey`。

## 测试与自检

```sh
go test ./...
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

`selfcheck` 使用隔离临时数据目录和真实 HTTP 监听，完成建档、底片上传、完整性检查、规则结论、冻结、签发和凭据校验后自行退出，不会改写正式数据目录。

## 数据说明

- `inspection.db`：任务聚合、修订与发现投影、冻结快照、凭据、幂等结果和审计事件。
- `radiographs/`：按 SHA-256 前缀分目录保存的原始底片载荷。
- 冻结快照和放行凭据都包含稳定摘要；服务启动与健康检查会验证 SQLite 和冻结证据完整性。
